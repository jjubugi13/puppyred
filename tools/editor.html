공지·패치 파일 편집기

여기서 수정해도 홈페이지는 바로 바뀌지 않아요. 파일로 저장 → GitHub의 data 폴더에 올리기까지 해야 반영됩니다. 비밀번호나 로그인은 필요 없어요.

먼저 수정할 목록을 불러오세요. 내려받은 파일로 이 편집기를 열었다면 ‘내 PC의 JSON 파일 열기’를 사용하세요.

줄바꿈은 그대로 표시돼요. 사진을 유지하려면 ![설명](./assets/notices/파일이름.png) 줄을 지우지 마세요. 패치 글은 빈 줄로 문단을 구분해 주세요.

저장한 뒤 GitHub data 폴더에서 Add file → Upload files로 파일을 올리고 Commit changes를 누르세요. 파일 이름은 notices.json 또는 patches.json 그대로 사용하세요.
